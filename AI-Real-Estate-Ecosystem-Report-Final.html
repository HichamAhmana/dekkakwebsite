Challenges & Blockers

Risk assessment and mitigation strategies

Current Technical Challenges

Challenge 1: Scalability Considerations

Current in-memory rate limiting resets on server restarts. For production scale, Upstash Redis or similar distributed cache is recommended.

Mitigation: Implement Redis-backed rate limiting before public launch. Estimated effort: 2-3 days.

Challenge 2: API Dependency Risks

Heavy reliance on external services (Resend, VirusTotal, Turnstile) creates potential points of failure. API rate limits and downtime could impact operations.

Mitigation: Implement fallback queues, circuit breakers, and graceful degradation patterns. Add API health monitoring.

Challenge 3: AI Orchestration Complexity

Multiple AI services require orchestration layer, prompt management, cost controls, and error handling. Without proper architecture, costs can escalate rapidly.

Mitigation: Deploy LangChain or similar orchestration framework. Implement usage quotas and cost alerts before AI rollout.

Challenge 4: Data Normalization

Current JSON-based content management lacks schema validation. Property data, investor profiles, and opportunity submissions have no unified structure.

Mitigation: Design and migrate to relational database (PostgreSQL) with strict schemas. Priority for Q3 2026.

Challenge 5: CRM Synchronization

No current CRM integration means manual data transfer for investor opportunities. This creates operational friction and potential data loss.

Mitigation: Evaluate Salesforce, HubSpot, or Pipedrive APIs. Build webhook-based sync architecture. Target: Q3 2026.
