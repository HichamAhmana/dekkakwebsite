Website Infrastructure

Technical architecture and deployment ecosystem

Core Architecture

The platform is built on Next.js 15, utilizing the App Router architecture for optimal performance and SEO capabilities. The infrastructure leverages React Server Components for reduced client-side JavaScript, implemented with a sophisticated component-based design system.

Component Technology Status Purpose
Frontend Framework Next.js 15.5.18 Active SSR, SSG, App Router
Language TypeScript 5 Active Type safety, IntelliSense
Styling CSS Modules + Inline Operational Component isolation
Deployment Vercel Production Edge deployment, CI/CD
Email Service Resend API Active Transactional emails
Bot Protection Cloudflare Turnstile Active CAPTCHA alternative
Deployment Pipeline Architecture
  • Development: Local Next.js dev server with hot reload
  • Git Repository: GitHub with branch protection
  • CI/CD: Vercel automated deployment on push
  • Edge Network: Global Vercel Edge for low-latency delivery
  • Environment: Production + Preview deployments per branch
Frontend Systems
  • Responsive design with mobile-first approach
  • CSS custom properties for theming
  • Dynamic route generation for blog posts
  • Image optimization with Next.js Image
  • Client-side navigation (SPA behavior)
Backend Systems
  • API Routes for form processing
  • Server-side rate limiting
  • File upload handling (base64)
  • Email orchestration via Resend
  • Static JSON data management
